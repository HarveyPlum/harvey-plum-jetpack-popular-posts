# Harvey Plum Jetpack Popular Posts Controls

Adds a WordPress admin GUI for Jetpack's Top Posts & Pages widget and shortcode filters, with a heavier focus on featured image presentation.

## Features

- Change the number of days Jetpack uses to calculate Top Posts.
- Add safe HTML before or after every Top Posts item.
- Choose featured-image treatments directly inside Jetpack's Top Posts & Pages widget form.
- Control aspect ratio, image focus, spacing, borders, border color, corner radius, shadows, and hover effects.
- Configure fallback images for posts without featured images.
- Override displayed item count.
- Filter popular posts by publish age, category, tag, excluded IDs, or current page.
- Add UTM parameters to Top Posts links.
- Apply image shape and custom CSS tweaks.

## Requirements

- WordPress 6.0 or newer.
- PHP 7.4 or newer.
- Jetpack with Stats and Extra Sidebar Widgets active.

## Usage

1. Upload and activate the plugin.
2. Open Appearance > Widgets and edit a Jetpack Top Posts & Pages widget.
3. Use the Harvey Plum display controls below Jetpack's built-in widget options.
4. Optional: open Settings > Jetpack Popular Posts to set site-wide defaults.
